Enable SSH / SFTP / rsync Remote Archive Sync
=============================================

Remote SSH host updates are DISABLED in code (July 2026). The research tool
still stages finished datasets locally under:

  scripts/research_tool/.tav_project_staging/
    finishedA/   — SPARC, FRB CSV archives
    finished2/   — Planck / integrator FITS
    finished/    — general finished exports

To push those archives to a remote host again, uncomment the marked blocks in
the files below (search for "disabled" or "Remote SSH").


1) Research tool — primary switch
---------------------------------
File: scripts/research_tool/tav_shared/tav_project_paths.py

  a) remote_transfer_enabled()
     Uncomment the os.environ.get("TAV_REMOTE_TRANSFER", ...) return.
     Remove or comment out the hard-coded `return False`.

  b) ensure_tav_project_dirs()
     Uncomment the block that calls rt.sftp_mkdir_p() for finishedA/finished2/finished.

  c) push_to_remote_public()
     Uncomment the SFTP upload body (remove the early `return None`).

  d) move_to_finished_archive()
     Uncomment the try/except block that calls push_to_remote_public().

  e) sync_staging_tree_to_remote()
     Uncomment the rsync body (remove the early skipped return).

5) Environment variables (required when enabled)
----------------------------------------------
Set before running the research tool, gateway /sync, or sync_archive:

  export TAV_REMOTE_USER="<ssh_user>"
  export TAV_REMOTE_HOST="<host_or_ip>"
  export TAV_REMOTE_PUBLIC="<remote_public_root>"          # e.g. /home/user/Public
  export TAV_REMOTE_TAV_PROJECT="<remote>/ProtonDrive/tav_project"
  export TAV_REMOTE_TSB_SYNC="<remote_public>/tsb_sync"
  export TAV_REMOTE_TRANSFER=1

Optional:
  export TAV_SSH_OPTS="-o BatchMode=yes -o ConnectTimeout=15"
  export TAV_SYNC_LOG="/path/to/sync.log"
  export TAV_STAGING="/path/to/research_tool/.tav_project_staging"


6) How to verify
----------------
From Research root:

  python3 scripts/remote_transfer.py          # SSH echo + remote ls (if __main__ restored)
  python3 scripts/sync_archive.py             # full corpus + staging sync
  ./scripts/llm  then  /sync                  # gateway sync command

From research_tool after a dataset fetch that archives to finishedA/finished2,
look for log lines:
  [TAV ENGINE] SFTP → user@host:...
  [TAV ENGINE] Uploaded <file> to remote Public archive
